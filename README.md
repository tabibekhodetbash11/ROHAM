# ROHAM — Neon Smart Dialer

پروژه اولیه شماره‌گیر اندروید با رابط تیره و نئونی، شماره‌گیر، فهرست مخاطبین و صفحه پایه تماس.

## ساخت APK
با هر push به شاخه `main`، GitHub Actions گردش‌کار ساخت را اجرا می‌کند. پس از پایان موفق:
1. وارد تب **Actions** مخزن شوید.
2. اجرای **Build ROHAM APK** را باز کنید.
3. در بخش **Artifacts** فایل `ROHAM-debug-apk` را دریافت کنید.

## نصب و راه‌اندازی
APK آزمایشی را روی گوشی نصب کنید. سپس از داخل برنامه، دکمه تنظیمات را بزنید و ROHAM را به‌عنوان برنامه پیش‌فرض تماس انتخاب کنید. مجوز مخاطبین و تماس را نیز به برنامه بدهید.

## وضعیت و محدودیت‌ها
این نسخه، نسخه اولیه توسعه است و هنوز روی POCO C40 آزمایش میدانی نشده است. رابط شماره‌گیر و فهرست مخاطبین پیاده‌سازی شده‌اند و شماره مخاطبین در فهرست نشان داده نمی‌شود؛ اطلاعات مخاطبین از دفترچه تلفن حذف یا تغییر نمی‌کند. صفحه تماس و سرویس InCall پایه هستند و امکاناتی مانند تاریخچه کامل تماس، مدیریت دقیق تماس پشت‌خطی، رد تماس ورودی و تست همه حالت‌های تماس هنوز نیازمند تکمیل و آزمایش‌اند. تا پیش از تست روی گوشی، آن را جایگزین قطعی برنامه تماس اصلی نکنید.
